How we work

Two problems that tighten each other.

Better data sharpens calibration, and understanding why a model is calibrated tells us which data to collect next.

  1. I.

    Calibration before confidence

    A stated probability should match how often the model is right. We measure that first, and report it with intervals.

  2. II.

    Claims travel with evidence

    Releases link artifacts, evaluation inputs, metric code, and limitations. Unresolved results are labelled as such.

  3. III.

    Open by default

    Weights, evaluation data, and code are public, so anyone can recompute the headline numbers.
