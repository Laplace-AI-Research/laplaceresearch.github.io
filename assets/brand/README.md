# Laplace Research brand mark

2000 × 2000 masters. SVGs are exact vector traces of the PNG masters (one five-point polygon).

| File | Use |
|---|---|
| `laplace-mark-white-on-navy.{svg,png}` | Social avatars (LinkedIn, GitHub, Hugging Face, X) |
| `laplace-mark-navy.{svg,png}` | Primary website mark (transparent) |
| `laplace-mark-navy-on-white.{svg,png}` | Navy mark on white |
| `laplace-mark-black-on-white.{svg,png}` | One-colour print, documents |
| `laplace-mark-black.{svg,png}` | Transparent, black |
| `laplace-mark-white.{svg,png}` | Transparent, for dark or photo backgrounds |

Colour: one navy, `#02338A`, for the mark, tiles and the site accent (`--accent` in `site.css`).
| `laplace-lockup-{color,navy,white,black}.{svg,png}` | Mark + "Laplace Research" wordmark, outlined (regenerate with `tools/generate_lockups.py`) |
| `laplace-research-brand-kit.zip` | Everything above, offered on `/brand/` |

Public guidelines: https://laplaceresearch.org/brand/
